# 📚 Student Study Assistant

## Project Overview
Student Study Assistant is an AI-powered application that helps students learn more effectively.

## Features
- 📄 Upload PDF notes
- 🤖 AI chatbot
- 📝 Chapter summarization
- ❓ Quiz generation
- 💡 Explain difficult topics
- 🔍 Ask questions from notes
- 📚 RAG-based document search

## Technologies Used
- Python
- Streamlit
- NLP
- LangChain
- FAISS
- RAG
- GitHub
